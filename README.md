# AWS Secure Baseline

A practical AWS security configuration project focused on secure
architecture, infrastructure as code, preventive controls and validation.

## Structure

- `docs/` — Architecture, controls and design decisions.
- `terraform/` — Infrastructure modules and lab environment.
- `app/` — Sample application and security scanning.
- `tests/` — Security validation tests.
- `.github/workflows/` — CI workflow.

## Status

Planned. Implementation and test results will be documented as completed.
